## Add a publication

Edit `_data/publications.yml` and add an entry like this anywhere in the file:

```yaml
- sort_date: "2027-04-15"
  text: >-
    [**Paper title**](https://example.com/journal-page), *Journal* **1** (2027),
    1–20.
```

The `sort_date` is used only for ordering and is not displayed. The website
automatically puts the newest paper first and updates the descending numbers.
